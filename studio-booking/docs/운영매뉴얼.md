## 매일 할 일

| 언제 | 할 일 | 어디서 |
| --- | --- | --- |
| 수시 | **촬영 지원 요청** 확정 / 시간 조정 후 확정 / 반려(사유 필수) | 담당자 화면 → 지원 요청 |
| 수시 | 전날 18:00 이후 걸려 온 **취소·변경 요청** 처리 | 예약 현황 → 시간 변경 / 취소(노쇼) / 취소(예외) |
| 수시 | 사전 연락이 확인된 노쇼 **해제** | 노쇼·제재 → 노쇼 해제 |

- 지원 요청을 **시작 시각까지 처리하지 않으면 자동 취소**되고 이용자에게 메일이 갑니다.
- **취소(노쇼)**는 노쇼 1회로 기록되고, **취소(예외)**는 기록되지 않습니다. 사전 연락이 있었다면 ‘예외’를 고르세요.
- 노쇼를 해제하면 그 노쇼로 걸린 예약 제한도 함께 풀립니다.

## 스튜디오를 잠시 막아야 할 때 (점검·행사)

해당 스튜디오의 구글 캘린더(“HY FLIP 셀프스튜디오 ST0x …”)에 **일정을 직접 추가**하세요.
- 종일 일정 → 그날 전체 예약 불가
- 시간 일정 → 그 시간만 예약 불가

캘린더가 유일한 기준 일정이라 별도 설정 없이 바로 반영됩니다.
단, **이용자 예약 일정을 캘린더에서 직접 지우지 마세요.** 시트 기록과 어긋납니다. 취소는 담당자 화면에서 하세요.

## 캘린더를 내 계정에서 보기

부서 계정으로 구글 캘린더 → 스튜디오 캘린더 ‘설정 및 공유’ → ‘특정 사용자와 공유’에 담당자 계정 추가(일정 변경 권한 불필요, ‘모든 일정 세부정보 보기’ 권장).
