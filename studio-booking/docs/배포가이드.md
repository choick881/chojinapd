# 배포 가이드 — 부서 공동계정(HY FLIP)으로 설치하기

> 소요 시간: 약 30분 · 필요한 것: PC 1대, **HY FLIP 부서 공동계정** 로그인, 인터넷
> 모든 스크립트·시트·캘린더는 이 계정 소유로 만들어집니다(기능정의서 2장).
> **부서 공동계정은 설치·소유용일 뿐입니다.** 배포 후 예약은 학교 구글 계정(@hanyang.ac.kr)이 있는 교수·강사·직원·조교 **누구나** 할 수 있습니다.

---

## 0. 준비 (최초 1회)

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전을 내려받아 설치합니다.
2. **Apps Script API 켜기** — 부서 공동계정으로 로그인한 브라우저에서 아래 주소를 열고 “Google Apps Script API”를 **사용**으로 바꿉니다.
   `https://script.google.com/home/usersettings`
3. **코드 받기** — GitHub 저장소에서 `Code → Download ZIP`으로 받아 압축을 풀고, `studio-booking` 폴더를 엽니다.
4. 그 폴더에서 터미널(Windows: 폴더 주소창에 `cmd` 입력 후 Enter)을 엽니다.

## 1. 명령어 5줄로 올리기

아래 명령어를 순서대로 한 줄씩 실행합니다.

```bash
npm install
```

```bash
npx clasp login
```
브라우저가 열리면 **부서 공동계정**을 고르고 “허용”을 누릅니다.

```bash
npm run create
```
새 Apps Script 프로젝트 “HY FLIP 셀프스튜디오 예약”이 만들어집니다.

```bash
npm run push
```
“Manifest file has been updated. Do you want to push and overwrite?”가 나오면 `y`를 입력합니다.

```bash
npm run open
```
Apps Script 편집기가 브라우저에서 열립니다.

## 2. 초기 설치 실행 (편집기에서)

1. 왼쪽 파일 목록에서 `Setup.gs`를 엽니다.
2. 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 누릅니다.
3. “권한 검토” → 부서 계정 선택 → (“확인되지 않은 앱” 경고가 나오면) **고급 → 이동** → **허용**.
4. 실행 로그에 `관리 시트: https://docs.google.com/...`가 나오면 성공입니다.
   - 관리 시트 1개, 스튜디오 캘린더 10개, 스튜디오별 QR키, 시간 트리거 4개가 자동으로 만들어집니다.
   - setup은 여러 번 실행해도 중복으로 만들지 않습니다.

## 3. 웹앱 배포 (편집기에서, 최초 1회)

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(톱니바퀴) → **웹 앱**을 고릅니다.
3. 설명: `HY FLIP 셀프스튜디오 예약 v1`
   - 다음 사용자로 실행: **나(부서 공동계정)**
   - 액세스 권한이 있는 사용자: **한양대학교 내 모든 사용자**
4. **배포** → 표시되는 **웹 앱 URL**(`…/exec`로 끝남)을 복사합니다.

## 4. 관리 시트 마무리 설정

관리 시트(2단계 로그의 주소)를 열고 아래를 채웁니다.

| 탭 | 할 일 |
| --- | --- |
| 설정 | **웹앱 주소**에 3단계 URL을 붙여 넣기 (메일·QR 링크용, 필수) |
| 설정 | **담당자 알림 메일**에 촬영 지원 요청을 받을 주소 입력 |
| 관리자 | 담당자 화면을 쓸 직원 이메일 추가 (부서 계정은 자동 등록됨) |
| 선정교수 | 선정 결과 발표 후 선정 교수 이메일 입력 → 8주 앞까지 우선 예약 |
| 학기 | 학사일정에 맞게 시작일·종료일 확인 (방학은 직전 학기에 포함) |
| 공휴일 | 개교기념일 등 학교 휴무일 추가 (법정 공휴일은 구글 공휴일 캘린더로 자동 반영) |

## 5. QR 인쇄·부착

1. 웹 앱 URL 끝에 `?p=admin`을 붙여 엽니다 → **QR 인쇄** 탭 → **인쇄하기**.
2. 각 스튜디오 출입문 옆에 붙입니다. 옆에 게시할 이용 안내문은 [이용수칙_샘플.md](이용수칙_샘플.md)의 B안을 쓰세요.

## 6. 시범 운영 점검표

- [ ] 교수 계정 2개로 같은 스튜디오·같은 시간을 동시에 예약 → 한 명만 성공
- [ ] 확정 메일 수신, 메일 속 “내 예약” 링크가 열림
- [ ] 촬영 지원 체크 → 담당자 알림 메일 → 담당자 화면에서 확정 → 결과 메일
- [ ] 스튜디오 QR로 체크인 → 담당자 화면 ‘예약 현황’에 체크인 표시
- [ ] 체크인 없이 시작 60분 경과 → 10분 안에 노쇼 처리·안내 메일
- [ ] 전날 18:00 이후 ‘내 예약’에서 취소 버튼이 사라짐
- [ ] 학교 밖 계정(gmail 등)으로 열면 접근 불가
- [ ] 교직원 계정·플립러닝 미신청 교수 계정·조교 계정으로 각각 예약 성공 (부서 계정이 아닌 개인 계정)
- [ ] 조교 계정에서 ‘교수님 대신 예약’ + 선정 교수 이메일 → 5주 뒤 날짜 예약 성공, 교수님께 참조 메일 도착

## 코드를 고친 뒤 다시 올릴 때 (URL 유지)

```bash
npm run push
```
그다음 편집기에서 **배포 → 배포 관리 → (기존 배포) 연필 아이콘 → 버전: 새 버전 → 배포**.
새 배포를 만들지 않아야 URL과 인쇄한 QR이 그대로 유지됩니다.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| `User has not enabled the Apps Script API` | 0-2단계(API 켜기)를 부서 계정으로 다시 확인 |
| clasp login이 학교 정책으로 막힘 | Workspace 관리자에게 clasp(Google Apps Script CLI) 허용 요청. 급하면 편집기에 파일을 직접 만들어 붙여 넣기(`src` 폴더의 파일 이름 그대로, `ui/App.html`은 편집기에서 `ui/App`) |
| “학교 구글 계정으로 로그인한 뒤…” 오류 | 배포 설정이 ‘실행: 나’, ‘액세스: 한양대학교 내 모든 사용자’인지 확인 |
| 메일 링크가 `/dev`로 열림 | 설정 탭 ‘웹앱 주소’에 `/exec` URL 입력 |
| QR 사진이 유출됨 | 편집기에서 `rotateQrKeys` 실행 → QR 다시 인쇄·부착 |

**사용량 한도(Google Workspace):** 메일 하루 1,500명, 캘린더 일정 생성은 하루 수천 건 수준으로 예약 규모에는 여유가 있습니다.
