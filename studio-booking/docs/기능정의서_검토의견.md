검토 자료: 「HY FLIP 신청·스튜디오 예약 시스템 기능정의서 v0.1」(2026-11-23), 「2027-1학기 플립러닝(Smart-F) 과목 콘텐츠 개발 신청 안내」 공문

## B. 정의서 문구 수정 제안

- **“캨린더” 오타**: 2장, 5장(5-1·5-3·5-4) 여러 곳이 깨진 글자 → “캘린더”로 수정.
- **5-1 ‘중복 방지’**: “캘린더 실시간 확인”이 그대로 구현됐습니다. 덧붙여 “담당자가 캘린더에 넣은 종일·시간 일정(점검·행사)도 예약을 막는다”를 명시하면 운영 매뉴얼과 맞습니다.
- **2장 ‘삭제’**: 예약 모듈은 2년 경과 시 예약 기록을 **행 전체 삭제**합니다(5장 예약 기록은 10년 이력 대상 아님). 스튜디오 이용 통계는 개인정보 없이 ‘통계’ 탭에 계속 남는다는 문장 추가 제안.
- **‘체크인 로그’**: 별도 탭 대신 예약 행의 ‘체크인일시’ 열로 통합했습니다(시트 1행 = 예약 1건 원칙 유지).

## C. 공문(2027-1학기 Smart-F 신청 안내)과의 연결

- 공문 5-다 제출서류에 아직 **“개인정보서약서 1부”**가 남아 있습니다. 정의서 6장 개정 문구(“온라인 신청 화면에서 동의, 별도 제출 불필요”)는 모듈 A 오픈 이후 공고부터 적용됩니다.
- 공문 4장 일정상 선정 결과 공문(12/15) 직후부터 촬영 수요가 생깁니다 → **예약 모듈은 12/15 전에 시범 오픈**하는 것이 좋습니다.
- 공문 3-가 강의 시수 인정 기준(주차당 25분/40분)은 모듈 A 신청 화면 안내문에 반영할 항목입니다.

## D. 추가로 구현한 편의 기능 (정의서에 없음 — 끄거나 바꿀 수 있음)

- 이용 전날 15시 **리마인더 메일** (설정 ‘전날 리마인더 메일’ = N 으로 끔)
- 촬영 지원 요청 시 **담당자 알림 메일** (설정 ‘담당자 알림 메일’ 비우면 끔)
- **예약 변경**: 마감 전이면 본인이 새 시간으로 바꾸기(새 예약 확정 후 기존 예약 자동 취소)
- **QR 인쇄 화면**: 담당자 화면에서 10곳 QR을 한 번에 인쇄
