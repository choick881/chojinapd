# 관리 시트 직접 입력 가이드 (2027-1 오픈 전)

코드가 아니라 **시트에 저장된 값**이라 담당자가 직접 넣어야 하는 항목입니다. **테스트용 사본과 실제 시트 둘 다** 같은 방법으로 넣습니다(테스트 사본은 PDF폴더ID만 다름).

> ⚠️ **12/5 오픈 전에 끝내야 합니다.** `학기종료일`은 교수님이 제출하는 순간 `신청목록` 행에 복사됩니다. 먼저 접수된 행은 나중에 설정을 바꿔도 따라 바뀌지 않습니다.

## 1. `설정` 탭 — 학기종료일 2027-06-21

`설정` 탭은 A열 **항목**, B열 **값** 두 칸입니다.

1. 관리 시트 아래쪽 탭에서 **`설정`**을 누릅니다.
2. A열에서 **`학기종료일`** 행을 찾습니다. 없으면 맨 아래 빈 행 A칸에 `학기종료일`(띄어쓰기 없이)을 적습니다.
3. 같은 행 **B칸**을 누르고 `2027-06-21`을 입력한 뒤 Enter.
4. **날짜로 들어갔는지 확인**합니다. 하나만 맞으면 됩니다.
   - 값이 칸 **오른쪽**으로 붙어 있다 (왼쪽에 붙으면 글자로 들어간 것)
   - 칸을 두 번 누르면 **달력**이 뜬다
5. 글자로 들어갔다면: B칸 선택 → 메뉴 **서식 > 숫자 > 날짜** → 다시 `2027-06-21` 입력.

> 날짜여야 하는 이유: 학기종료일 + 2년(2029-06-21 무렵)에 이메일·휴대폰·PDF를 자동 삭제하는데, 글자로 들어가면 삭제일이 계산되지 않습니다.

## 2. `설정` 탭 — Smart-B 최소주차 4 (선택)

비워 두면 코드가 **4주**로 처리하므로 넣지 않아도 동작합니다. 시트에서 값을 눈으로 확인하고 싶으면:

1. A열에 `Smart-B 최소주차` 행이 있는지 봅니다. (`Smart-F 최소주차` 바로 아래가 보기 좋습니다)
2. 없으면 빈 행 A칸에 **`Smart-B 최소주차`** — `Smart`, `-`, `B`, **띄어쓰기 한 칸**, `최소주차` — 를 그대로 적습니다. 글자가 하나라도 다르면 무시되고 4주가 적용됩니다.
3. B칸에 숫자 `4`.

## 3. `메일문구` 탭 — 접수안내 본문에서 서약서 문구 빼기

`메일문구` 탭은 A **구분**, B **설명**, C **제목**, D **본문** 4칸입니다. 교수님이 제출하는 즉시 **접수안내** 행의 제목·본문으로 메일이 나갑니다.

1. **`메일문구`** 탭 → A열이 **`접수안내`**인 행을 찾습니다.
2. 그 행 **D칸(본문)**을 누르고, 화면 위 **수식 입력줄**을 눌러 편집합니다. (본문이 길어서 칸 안보다 수식 입력줄이 편합니다. 줄을 바꾸려면 **Ctrl+Enter**(맥은 ⌘+Enter), 그냥 Enter는 입력 완료)
3. “개인정보서약서 1부” 같은 문구를 지우고 아래 문장으로 바꿉니다.

   ```
   서명한 신청서 1부를 소속 단과대학 RC 행정팀을 경유해 그룹웨어 공문으로 제출해 주십시오({마감일시}까지).
   개인정보서약서는 온라인 동의로 대신하므로 따로 내지 않으셔도 됩니다. 동의 내역(동의 일시 포함)은 신청서 PDF 마지막 쪽에 들어 있습니다.
   ```
4. **`{중괄호}` 안 글자는 고치지 마세요.** 메일을 보낼 때 실제 값으로 바뀝니다. 철자가 틀리면 `{마감일시}`처럼 괄호째 그대로 나갑니다.

   | 쓸 수 있는 칸 | 들어가는 값 |
   | --- | --- |
   | `{교수명}` `{과목명}` `{학기}` `{접수번호}` `{수업유형}` | 신청서 내용 |
   | `{최소주차}` | Smart-F는 8주, Smart-B는 4주 |
   | `{마감일시}` `{개발기간}` `{담당자연락처}` `{신청페이지URL}` | `설정` 탭 값 |
   | `{PDF링크}` | 이 신청서 PDF 주소 |
   | `{미선정사유}` `{보완내용}` `{보완기한}` | 미선정·보완요청 메일용 |

5. **C칸(제목)은 비우지 마세요.** 제목에 `발송 없음`이라고 적으면 그 메일은 아예 나가지 않습니다.

## 4. 넣은 뒤 확인 (2분)

1. 시트 메뉴 **확장 프로그램 > Apps Script** → 위쪽 함수 목록에서 **`setup`** 선택 → **실행**.
   - “설치 완료”가 나오면 열·메일문구 4종이 모두 정상입니다.
   - 오류가 나면 메시지에 빠진 열이나 메일 구분 이름이 나옵니다.
2. **테스트용 사본**에서 직접 한 건 제출해 봅니다.
   - 받은 접수안내 메일에 서약서 문구가 없고, `{ }`가 그대로 남은 곳이 없는지 확인합니다.
   - `신청목록` 새 행의 `학기종료일` 칸이 2027-06-21이고, `개인정보삭제일` 칸이 비어 있지 않은지 확인합니다.
   - PDF 마지막 쪽에 ‘개인정보 수집·이용 동의 내역’과 동의 일시가 있는지 확인합니다.
