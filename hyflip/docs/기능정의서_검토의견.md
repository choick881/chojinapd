## B. 정의서 문구 수정 제안

- **신청 계정**: “책임교수 본인 구글 계정으로 신청(대리신청 불가). 접수·선정 메일과 PDF는 신청 계정으로만 발송”을 명시.
- **주차별 설계**: “8·16주차 시험 고정”을 “주차별 유형 선택(기본값 8·16주차 시험)”으로 수정. 15주 운영·7주차 중간고사 사례가 실제로 있음.
- **보관기간**: 미제출 임시저장도 마지막 저장일로부터 2년 뒤 자동 삭제(삭제대장 기록)된다는 문장 추가.
- **PDF**: “제출 시 신청서 PDF 자동 생성, 수정 재제출 시 새 PDF로 교체(이전 PDF 휴지통)” 명시.

## D. 추가로 구현한 편의 기능 · 개선 제안 (정의서에 없음)

구현됨
- **임시저장**: 단계 이동 때 자동 저장 + 버튼 저장. 응답 전에 연달아 눌러도 임시저장 행이 1개만 생김.
- **과목 검색 자동 채움**: 학수번호·과목명·담당교수로 검색, 선택하면 과목 정보 자동 입력.
- **평가 비율 합계 표시**: 100%가 아니면 빨간색 + 다음 단계 차단.
- **`setup` 점검**: 필수 열·메일문구 4종이 없으면 설치 단계에서 오류로 알려 줌.
- **모바일 카드형 목록(11/25)**: 화면 폭 640px 이하에서는 ‘내 신청서’를 표 대신 카드(과목명·상태·접수번호·저장일시 + 열기·PDF 버튼)로 보여 줌. PC·태블릿은 기존 표 그대로. [캡처 01](screenshots/01-mobile-home.png)
