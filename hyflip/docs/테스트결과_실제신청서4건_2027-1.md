## 2. 무엇을 어떻게 확인했나

### 화면 입력 → 제출 (교수 4명, 각자 학교 계정)
브라우저에서 교수님이 하듯 1~6단계를 그대로 눌러 입력했습니다.
1. 동의
2. 과목 검색 후 선택(자동 채움), 기본정보
3. 개요 6칸 (원본 긴 본문 그대로)
4. Pre/In/Post, 평가항목(B는 6개라 "+ 평가항목 추가"), 평가기준·교재
5. 16주 유형·주제·활동·소요시간
6. 제출

제출 뒤 시트에 저장된 내용을 원본 샘플과 **칸마다 대조**했고, A·C·D 모두 일치했습니다.

### B 아동건강간호 — 막혀야 정상
- 영상 주차가 2~5주 4주뿐이라 **Smart-F 최소 8주**에 못 미칩니다.
  - 화면에서는 "Smart-F는 영상 개발 주차가 8주 이상이어야 합니다(현재 4주)"가 뜨고 다음 단계로 못 넘어갑니다.
  - 화면을 거치지 않고 서버에 바로 제출해도 거절됩니다.
- 입력한 내용은 임시저장(미제출)으로 남아 교수님이 고칠 수 있습니다. [캡처](screenshots/samples/B-1-blocked.png)
- 11/25 결정(Smart-B 접수)에 따라 수업유형만 **Smart-B**로 바꾸면 최소 4주 기준으로 접수되는 것도 확인했습니다. 다만 B는 오프라인 주차가 많아 실제로는 Smart-B 성격과 다릅니다. 규칙만 확인한 것입니다.

## 3. 원본 신청서에서 발견한 점 → 온라인 신청서가 막아 주는 것

| 원본 (종이·한글 서식) | 온라인 신청서 |
| --- | --- |
| A·D 표지 "2026학년도 **1**학기" ↔ 개설시기 "2026년 **2**학기" (서로 다름) | 학기는 `설정`의 모집학기로 **자동 입력** |
| A 소속 칸에 **성명**이 적힘 | 소속·직위·성명 칸이 따로 있고 모두 필수 |
| A 주차표가 한 칸씩 밀림 (7주차 제목은 중간고사인데 시험 내용은 8·16주차 칸) | 주차마다 **유형(영상·오프라인·시험·운영 안 함)**을 고르고 영상 주차를 자동 계산 |
| B 3~4주·8~15주를 셀 병합, 16주차 없음 | 1~16주를 하나씩 입력, 운영 안 하는 주는 '운영 안 함' |
| A 평가항목 '참여 10%' ↔ 평가기준 '과제' | 평가항목·비율·전략이 한 줄에 함께 있고 합계 100% 자동 확인 |
| 옛 서식에 **촬영방식·개발구분·전공구분** 칸 없음 | 새로 생긴 필수 칸 → 테스트에서는 임의 값으로 채움 |
| D 시험 주차에 "중간고사로 대체(30·130·20·20분)" 활동 기재 | 시험 주차는 **주제·소요시간만** 입력 (활동 칸 없음). 필요하면 주제에 적도록 안내 |

## 4. 결정 사항 (11/25 조피디님 확정 — 현재 구현 그대로, 코드 변경 없음)

1. **최소 영상 주차는 학점과 관계없음**
   - 2학점이든 3학점이든 **Smart-F는 8주 이상, Smart-B는 4주 이상** 동영상을 개발하는 것이 원칙입니다.
   - 2학점 Smart-F인 B(영상 4주)가 막히는 것은 정상입니다. 교수님께는 영상 주차를 8주 이상으로 늘리도록 안내합니다.
2. **시험 주차 활동 기재는 지금 그대로**
   - 시험·평가 주차는 주제와 소요시간만 받습니다. 활동 칸은 없습니다.
