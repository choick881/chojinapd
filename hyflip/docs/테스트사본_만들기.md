# 테스트 사본 만들기 — 브라우저만으로 30분

12/4 내부 테스트용 **시트 사본**과 **테스트 신청 페이지**를 만듭니다. PC에 프로그램을 설치하지 않고, 크롬 같은 브라우저만으로 할 수 있습니다.

> ✅ **처음부터 끝까지 `hyflip@hanyang.ac.kr`로 로그인한 상태에서** 진행하세요. 개인 계정으로 만들면 교수님들이 접근 거부 화면을 보게 됩니다.
> ⚠️ 테스트 사본에서도 **메일은 실제로 나갑니다.** 학교 테스트 계정끼리만 신청해 보세요.
> 실제 신청 페이지는 이 사본으로 테스트를 마친 뒤 따로 만듭니다(설치가이드). 이 사본을 바꿔도 실제 페이지에는 영향이 없습니다.

| 단계 | 할 일 | 시간 |
| --- | --- | --- |
| 0 | 시트 사본 만들기 | 3분 |
| 1 | 테스트 PDF 폴더 만들기 | 2분 |
| 2~4 | `설정`·`개설과목`·`메일문구` 탭 입력 | 10분 |
| 5 | 코드 붙여넣기 | 7분 |
| 6~7 | `setup` 실행, 웹 앱 배포 | 5분 |
| 8 | 열어서 확인 | 5분 |

## 0. 시트 사본 만들기

- **실제 데이터 시트가 이미 있으면:** 시트를 열고 **파일 > 사본 만들기**를 누릅니다. 이름은 `HYFLIP_신청시스템_테스트`로 합니다.
- **아직 없으면:** `HYFLIP_신청시스템_데이터시트_v1.0.xlsx`를 드라이브에 올리고 열어서 **파일 > Google Sheets로 저장**을 누릅니다. 이름은 `HYFLIP_신청시스템_테스트`로 바꿉니다.
  - 회색 예시 행(2행)은 지웁니다. 대상은 `신청목록`·`신청상세`·`개설과목`이고, `신청목록`은 **행 전체 삭제**로 지웁니다.
  - 탭 이름과 1행의 열 이름은 **바꾸지 마세요.**

## 1. 테스트 PDF 폴더 만들기

1. 드라이브에서 **새로 만들기 > 새 폴더**를 누르고 이름을 `HYFLIP_신청서PDF_테스트`로 합니다.
2. 폴더를 열면 주소창이 `…/drive/folders/1AbC…` 형태입니다. **`folders/` 뒤 문자열**을 복사해 둡니다. 이것이 폴더 ID입니다.

## 2. `설정` 탭 — 테스트용 값

A열이 항목, B열이 값입니다. 항목이 없으면 빈 행에 새로 적습니다(띄어쓰기까지 똑같이).

| 항목 | 테스트 사본에 넣을 값 | 실제 시트와 다른가 |
| --- | --- | --- |
| 모집학기 | `2027-1` — 먼저 칸을 **서식 > 숫자 > 일반 텍스트**로 | 같음 |
| 신청시작 | **오늘 날짜 09:00** (예: `2026-11-26 09:00`) | ⚠️ 다름 (실제는 12/5 09:00) |
| 신청마감 | **`2026-12-31 17:00`** | ⚠️ 다름 (실제는 12/14 17:00) |
| 개발기간시작 | `2026-12-15` | 같음 |
| 개발기간종료 | `2027-02-19` | 같음 |
| 담당자연락처 | `에듀테크혁신팀 02-2220-1406` | 같음 |
| 발신계정 | `hyflip@hanyang.ac.kr` | 같음 |
| Smart-F 최소주차 | `8` | 같음 |
| Smart-B 최소주차 | `4` | 같음 |
| 학기종료일 | `2027-06-21` — 칸 **오른쪽**에 붙으면 날짜로 들어간 것 | 같음 |
| 허용도메인 | `hanyang.ac.kr` (이미 있으면 그대로) | 같음 |
| PDF폴더ID | **1단계에서 복사한 테스트 폴더 ID** | ⚠️ 다름 |
| 신청페이지URL | (7단계 배포 후 입력) | ⚠️ 다름 |

> 신청시작을 12/5로 두면 12/4 테스트 때 "지금은 신청기간이 아닙니다"가 나와 신청할 수 없습니다. 그래서 테스트 사본만 신청기간을 앞당깁니다.

## 3. `개설과목` 탭 — 테스트 과목 4줄

1. A열(학기) 전체를 선택하고 **서식 > 숫자 > 일반 텍스트**로 바꿉니다.
2. 2행 A칸을 누르고 아래 4줄을 붙여넣습니다(탭으로 구분된 표라 칸에 맞게 들어갑니다).

```
2027-1	TEST0001	01	문화산업의회계및세무	Accounting & Taxation	경영학과	3	1	테스트교수A
2027-1	TEST0002	01	아동건강간호	CHILD HEALTH NURSING	간호학과	2	4	테스트교수B
2027-1	TEST0003	01	지속가능경영시스템	Sustainable Management System	경영공학	3	전체	테스트교수C
2027-1	TEST0004	01	고급표현학습	Advanced Representation Learning	인공지능학과	3	대학원	테스트교수D
```

각 과목의 화면 입력값은 [테스트샘플_입력용.md](테스트샘플_입력용.md)에 있습니다.

## 4. `메일문구` 탭 — 접수안내 본문

A열이 `접수안내`인 행의 **D칸(본문)**에서 "개인정보서약서 1부" 문구를 지우고 아래 문장으로 바꿉니다. 자세한 방법은 [시트 직접 입력 가이드 3장](시트_직접입력_가이드.md)에 있습니다.

```
서명한 신청서 1부를 소속 단과대학 RC 행정팀을 경유해 그룹웨어 공문으로 제출해 주십시오({마감일시}까지).
개인정보서약서는 온라인 동의로 대신하므로 따로 내지 않으셔도 됩니다. 동의 내역(동의 일시 포함)은 신청서 PDF 마지막 쪽에 들어 있습니다.
```

## 5. 코드 붙여넣기

1. 사본 시트에서 **확장 프로그램 > Apps Script**를 엽니다. 새 탭에 편집기가 열립니다.
2. 아래 **원문 링크**를 하나씩 열고, **Ctrl+A(전체 선택) → Ctrl+C(복사)** 한 뒤 편집기의 해당 파일에 **전체를 덮어쓰기**합니다.

| 편집기 파일 | 없으면 만드는 법 | 원문 링크 (열어서 전체 복사) |
| --- | --- | --- |
| `Code.gs` | 기본으로 있음 | [Code.gs](https://raw.githubusercontent.com/choick881/chojinapd/claude/zealous-lamport-jvjh6c/hyflip/src/Code.gs) |
| `Index.html` | 파일 옆 **+ > HTML**, 이름 `Index` | [Index.html](https://raw.githubusercontent.com/choick881/chojinapd/claude/zealous-lamport-jvjh6c/hyflip/src/Index.html) |
| `Pdf.html` | 파일 옆 **+ > HTML**, 이름 `Pdf` | [Pdf.html](https://raw.githubusercontent.com/choick881/chojinapd/claude/zealous-lamport-jvjh6c/hyflip/src/Pdf.html) |
| `appsscript.json` | 왼쪽 **⚙ 프로젝트 설정** > **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 체크 | [appsscript.json](https://raw.githubusercontent.com/choick881/chojinapd/claude/zealous-lamport-jvjh6c/hyflip/src/appsscript.json) |

3. 위쪽 **💾 저장**(Ctrl+S)을 누릅니다.

- 파일 이름은 **대소문자까지 정확히** 맞춥니다: `Index`, `Pdf`. 확장자 `.html`은 자동으로 붙습니다.
- `appsscript.json`에 시간대(서울)와 웹 앱 설정이 들어 있어 따로 바꿀 필요가 없습니다.

> 이 링크는 지금 검토 중인 최신 코드(PR #3)입니다. PR이 병합되면 주소의 `claude/zealous-lamport-jvjh6c`가 `main`으로 바뀝니다.

## 6. `setup` 실행

1. 편집기 위쪽 함수 목록에서 **`setup`**을 고르고 **▶ 실행**을 누릅니다.
2. "권한 검토" 창이 뜨면 **hyflip@hanyang.ac.kr**을 고르고 **허용**을 누릅니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 > (안전하지 않음)으로 이동**을 누르고 허용합니다. 우리 부서가 직접 만든 스크립트라 나오는 경고입니다.
3. 아래 실행 로그에 **"설치 완료: 트리거 2개"**가 나오면 성공입니다.
   - 오류가 나면 메시지에 빠진 열이나 설정값 이름이 나옵니다. 그 항목을 고치고 다시 실행합니다.

## 7. 웹 앱 배포

1. 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. ⚙(유형 선택)에서 **웹 앱**을 고릅니다.
   - 설명: `2027-1 테스트`
   - 다음 사용자 인증 정보로 실행: **나 (hyflip@hanyang.ac.kr)**
   - 액세스 권한이 있는 사용자: **한양대학교 내 모든 사용자**
3. **배포**를 누르고 나온 **웹 앱 URL**을 복사합니다.
4. 시트 `설정` 탭의 **신청페이지URL**에 붙여넣습니다.

> 나중에 코드를 바꾸면 **배포 > 배포 관리 > ✏️ 편집 > 버전: 새 버전 > 배포**를 누릅니다. 이렇게 하면 URL이 그대로 유지됩니다.

## 8. 열어서 확인 (5분)

| 확인 | 방법 | 정상 결과 |
| --- | --- | --- |
| 교수 화면 | **다른 학교 계정**(교수 역할)으로 웹 앱 URL 열기 | 2027-1 모집 안내와 "새 신청서 작성" 버튼 |
| 접수 | 테스트샘플 A를 입력해 제출 | 접수번호 `FL-2027-1-001`, 완료 화면 |
| 메일 | 그 계정 메일함(스팸함 포함) | 접수 안내 메일 1통, 답장 주소 hyflip@hanyang.ac.kr |
| PDF | 드라이브 `HYFLIP_신청서PDF_테스트` | PDF 1개, 한글·표가 깨지지 않음, 마지막 쪽에 동의 내역 |
| 시트 | `신청목록` 탭 | 새 행, 학기 `2027-1`, 학기종료일 2027-06-21 |
| 접근 거부 | 개인 Gmail로 URL 열기 | "접근 권한이 없습니다" |

이어서 [12/4 점검표](1204-checklist.html)를 차례로 확인하면 됩니다.

## 부록: PC에 Node.js가 있다면 — 설정 마법사

5~7단계(코드 넣기·배포)를 명령 한 줄로 할 수 있습니다. 0~4단계(시트 사본과 값 입력)는 위와 같이 먼저 합니다.

```bash
git clone -b claude/zealous-lamport-jvjh6c https://github.com/choick881/chojinapd.git
```

```bash
cd chojinapd/hyflip
```

```bash
npm run setup:google
```

마법사가 안내하는 대로 hyflip@hanyang.ac.kr로 로그인하고, 사본의 스크립트 ID를 붙여넣으면 됩니다. 자세한 내용은 [배포자동화.md](배포자동화.md)에 있습니다.
