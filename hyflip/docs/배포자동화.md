# 배포 자동화 가이드 (clasp)

지금은 Apps Script 편집기에 코드를 **복사·붙여넣기**해서 배포합니다. 아래처럼 바꾸면 GitHub에 있는 코드를 명령 한 줄, 또는 GitHub 버튼 한 번으로 올리고 배포할 수 있습니다.

```
GitHub 저장소 ──(자동 테스트 통과)──> clasp push ──> clasp deploy (URL 그대로)
                                   ├─ test : 테스트용 시트 사본  (12/4 내부 테스트)
                                   └─ prod : 실제 신청 페이지
```

배포 대상은 두 개입니다. **12/4 내부 테스트는 test로 하고, 통과하면 prod에 같은 코드를 올립니다.** 실제 신청 페이지와 데이터를 건드리지 않고 테스트할 수 있습니다.

---

> 💡 PC에 Node.js·git이 없으면 **브라우저만으로** 하는 [테스트사본_만들기.md](테스트사본_만들기.md)를 따라 하세요.

## 가장 쉬운 방법: 설정 마법사 (추천)

아래 1~4단계를 명령 한 줄로 진행합니다. 마법사가 페이지를 열고 기다리며, 클릭이 필요한 순간에만 "👉 직접 하실 일"을 알려 줍니다.

```bash
cd chojinapd/hyflip
npm run setup:google
```

직접 하실 일은 네 가지뿐입니다: ① Apps Script API "사용" 클릭 ② 부서 공동계정으로 로그인·허용 ③ 시트 사본 만들고 스크립트 ID 붙여넣기 ④ 편집기에서 `setup` 실행·권한 허용. 마법사는 코드 올리기, 테스트용 웹 앱 배포, `.env.test` 작성까지 해 주고 테스트용 신청 페이지 주소를 알려 줍니다. 실제 신청 페이지(prod)는 건드리지 않습니다. 다시 실행해도 같은 URL로 갱신됩니다.

## 조피디님이 직접 하셔야 하는 일 (처음 한 번, 마법사 없이 할 때)

구글 계정 로그인이 필요한 일이라 대신할 수 없습니다. 모두 **부서 공동계정 `hyflip@hanyang.ac.kr`**로 하세요.

| 순서 | 할 일 | 걸리는 시간 |
| --- | --- | --- |
| 1 | Apps Script API 켜기 | 1분 |
| 2 | 테스트용 시트 사본 만들고 설치 | 15분 |
| 3 | PC에서 clasp 로그인 | 5분 |
| 4 | 스크립트 ID·배포 ID를 `.env.test`, `.env.prod`에 적기 | 5분 |

### 1. Apps Script API 켜기

https://script.google.com/home/usersettings 에서 **Google Apps Script API**를 **사용**으로 바꿉니다.

### 2. 테스트용 시트 사본 만들기

1. 실제 데이터 시트를 열고 **파일 > 사본 만들기**를 누릅니다. 이름은 `HYFLIP_신청시스템_테스트`로 합니다.
   - 사본에는 Apps Script도 함께 복사됩니다. 트리거와 배포는 복사되지 않습니다.
2. 사본의 `설정` 탭을 바꿉니다.
   - `PDF폴더ID`: 드라이브에 `HYFLIP_신청서PDF_테스트` 폴더를 새로 만들고 그 ID를 넣습니다. 테스트 PDF가 실제 폴더에 섞이지 않습니다.
   - `신청마감`: 테스트 기간 동안 열려 있도록 넉넉히 잡습니다.
3. 사본에서 **확장 프로그램 > Apps Script**를 열고 `setup`을 실행합니다. "설치 완료: 트리거 2개"가 나오면 됩니다.
4. **배포 > 새 배포 > 웹 앱**으로 배포합니다(실행 사용자: 나, 액세스: 한양대학교 내 모든 사용자). 나온 URL을 사본 `설정` 탭의 `신청페이지URL`에 넣습니다.

> 테스트용 사본에서도 메일은 실제로 나갑니다. 테스트 계정끼리만 신청하세요.

### 3. PC에서 clasp 로그인

PC에 Node.js 18 이상이 있어야 합니다.

```bash
git clone -b claude/zealous-lamport-jvjh6c https://github.com/choick881/chojinapd.git   # PR 병합 전까지는 작업 브랜치
cd chojinapd/hyflip
npm install
npx clasp login          # 브라우저가 열리면 부서 공동계정으로 로그인
```

### 4. 스크립트 ID와 배포 ID 적기

`.env.example`을 두 번 복사해 `.env.test`와 `.env.prod`를 만들고, 각각 값을 넣습니다.

```
HYFLIP_SCRIPT_ID=1AbC...       # Apps Script > ⚙ 프로젝트 설정 > 스크립트 ID
HYFLIP_DEPLOYMENT_ID=AKfy...   # 아래 명령으로 확인
```

배포 ID 확인 방법: `.clasp.json`을 잠시 `{"scriptId":"스크립트ID","rootDir":"src"}`로 만든 뒤 `npx clasp deployments`를 실행합니다. `@HEAD`가 아닌 줄의 `AKfy...` 값이 웹 앱 배포 ID입니다. 이 ID로 갱신해야 URL이 바뀌지 않습니다.

> `.env.test`, `.env.prod`, `.clasp.json`, 로그인 정보(`~/.clasprc.json`)는 GitHub에 올라가지 않습니다.

## 배포할 때마다 (PC에서)

```bash
cd chojinapd/hyflip
git pull
npm run deploy:test -- "v1.0.2 내부 테스트"     # 테스트용 사본
npm run deploy:prod -- "v1.0.2"                 # 실제 신청 페이지
```

스크립트가 하는 일:

1. 문법 검사와 자동 테스트 35개를 돌립니다. 하나라도 실패하면 멈춥니다.
2. 확인을 받은 뒤 Apps Script 코드를 `src/` 내용으로 덮어씁니다(`clasp push`).
3. 한 번 더 확인을 받은 뒤 기존 웹 앱을 새 버전으로 갱신합니다(`clasp deploy -i`). URL은 그대로입니다.

test는 `y`, prod는 실수를 막기 위해 **`배포`라고 직접 입력**해야 진행합니다.

배포 후 Apps Script 편집기에서 `setup`을 한 번 실행해 "설치 완료: 트리거 2개"를 확인하세요. 트리거는 중복으로 생기지 않습니다.

## GitHub 버튼으로 배포 (선택)

PC 없이 GitHub 웹에서 배포할 수 있습니다. **자동으로는 절대 돌지 않고, 버튼을 눌러야만 실행됩니다.**

### 준비 (한 번)

1. 위 3단계로 로그인한 PC에서 `~/.clasprc.json` 파일 내용을 복사합니다. (Windows: `C:\Users\사용자명\.clasprc.json`)
2. GitHub 저장소 **Settings > Environments**에서 `hyflip-test`, `hyflip-prod` 두 환경을 만듭니다.
   - `hyflip-prod`에는 **Required reviewers**에 본인을 넣어 두세요. 버튼을 눌러도 승인해야 배포됩니다.
3. 각 환경에 비밀값 세 개를 넣습니다: `CLASPRC_JSON`(1번 내용), `HYFLIP_SCRIPT_ID`, `HYFLIP_DEPLOYMENT_ID`.

### 배포

**Actions > HY FLIP 배포 (수동 실행) > Run workflow**에서 대상(test/prod)과 설명을 고르고 실행합니다. prod는 `main` 브랜치에서만 됩니다.

> **보안 참고:** `CLASPRC_JSON`은 부서 공동계정의 Apps Script·드라이브 권한을 가진 로그인 토큰입니다. 저장소 관리자 외에는 접근하지 못하게 하고, 담당자가 바뀌면 https://myaccount.google.com/permissions 에서 clasp 권한을 해제한 뒤 다시 로그인해 갱신하세요. 학교 보안 정책상 외부 저장이 어렵다면 이 부분은 건너뛰고 PC 배포만 쓰면 됩니다.

## 주의할 점

- **`appsscript.json`도 함께 올라갑니다.** 시간대(서울), V8, 웹 앱 설정(실행 사용자 = 나, 액세스 = 도메인)이 들어 있습니다. 편집기에서 바꾼 설정이 있으면 이 파일에 먼저 반영하세요.
- **편집기에서 직접 고친 코드는 push 때 사라집니다.** 앞으로 코드 수정은 저장소에서만 하세요. 편집기에서 급히 고쳤다면 `npx clasp pull`로 먼저 가져와 커밋하세요.
- **시트 내용은 건드리지 않습니다.** clasp는 스크립트만 다룹니다. 탭·열·메일 문구는 여전히 시트에서 직접 관리합니다.
