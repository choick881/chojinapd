## 선정상태 바꾸기 (메일 자동 발송)

`신청목록`의 `선정상태` 칸을 드롭다운에서 고르면 바로 처리됩니다.

| 고른 값 | 미리 채울 칸 | 결과 |
| --- | --- | --- |
| 심의중 | – | 메일 없음, 상태변경일시 기록 |
| 선정 | – | ‘선정’ 메일 발송, `메일발송` = Y |
| 미선정 | **미선정사유** | ‘미선정’ 메일 발송 |
| 보완요청 | **보완내용, 보완기한** | ‘보완요청’ 메일 발송. 교수님은 보완기한 날 자정까지 수정·재제출 가능 → 재제출하면 상태가 ‘접수’로 돌아감 |

- 필요한 칸이 비어 있으면 메일이 가지 않고 칸에 메모(“메일 미발송: … 입력 후 상태를 다시 선택하세요”)가 붙습니다. 칸을 채우고 **상태를 다시 고르세요.**
- 여러 행을 한꺼번에 붙여넣거나 끌어 채우면 **메일이 가지 않습니다**(한 칸씩 바꿀 때만 동작). 한꺼번에 바꿔야 하면 한 행씩 고르세요.
- 메일은 신청 교수 본인 계정으로만 갑니다(참조 없음).

## 관리 시트 탭 안내

| 탭 | 용도 | 직접 고쳐도 되나 |
| --- | --- | --- |
| 설정 | 모집학기·신청기간·개발기간·연락처·최소주차·PDF폴더ID·학기종료일 | 예 (바로 반영). 모집학기는 **일반 텍스트** 서식 |
