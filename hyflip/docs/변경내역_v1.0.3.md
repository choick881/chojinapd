# HY FLIP 신청 모듈 변경내역 (v1.0.2 → v1.0.3)

2026-11-25 · 지난 학기 실제 신청서 4건으로 확인한 문제를 고쳤습니다.

## 왜 바꿨나

v1.0.2는 8주차·16주차를 시험으로 고정하고, "영상 개발 주차 수"를 교수님이 숫자로 적게 했습니다. 실제 신청서 4건 중 3건이 이 틀과 맞지 않았습니다.

- 7주차 중간고사 (2건)
- 15주 운영, 15주차 기말고사 (2건)
- 16주차를 기말고사 대신 기말과제 평가로 운영 (1건)

## 바뀐 점

| 파일 | 내용 |
| --- | --- |
| Index.html | 주차마다 **유형**을 고릅니다: 영상(플립) / 오프라인 수업 / 시험·평가 / 운영 안 함. 기본값은 예전과 같습니다(8·16주차 시험, 나머지 영상) |
| Index.html | 기본정보의 "영상 개발 주차 수"는 입력 칸 대신 자동 계산값을 보여 줍니다. 최소 주차 검사는 주차별 설계 단계로 옮겼습니다 |
| Code.gs | `weekType_`, `videoWeeks_` 추가. 영상 주차 수를 주차 유형으로 계산해 `신청목록`의 영상주차수와 PDF에 씁니다 |
| Code.gs | 학습주제 필수 검사는 영상·오프라인 주차에만 적용합니다 |
| Pdf.html | 주차 표의 주차 번호 아래에 유형(영상·오프라인·시험·미운영)을 표시합니다 |

## 바뀌지 않은 점

- 시트 탭과 열 구조. 주차 유형은 기존 `데이터(JSON)` 칸 안에 저장됩니다.
- 유형이 없는 예전 저장본은 예전 규칙(8·16주차 시험, 직접 적은 영상 주차 수)으로 읽고, 교수님이 다시 열면 유형이 채워집니다.

## 테스트

- 실제 신청서 4건(비식별)을 원본 주차 구성 그대로 넣어 A·C·D는 접수, B(영상 4주)는 막히는지 확인합니다.
- 영상 주차 숫자를 부풀려 적어도 주차 유형 기준으로 막히는지 확인합니다.
- 자동 테스트 35개 통과.
