# HY FLIP 신청 모듈 설치 가이드 (v1.0.2)

> v1.0.2부터 **대리신청 기능이 없습니다.** 책임교수님 본인 학교 계정으로만 신청·수정·제출할 수 있습니다.

함께 쓰는 파일은 다섯 개입니다.

- 데이터 시트: `HYFLIP_신청시스템_데이터시트_v1.0.xlsx`
- 스크립트: `Code.gs`, `Index.html`, `Pdf.html`
- 이 가이드

모든 작업은 **부서 공동계정**으로 로그인해서 진행하세요.

---

## 1. 데이터 시트 올리기

1. 부서 공동계정 구글 드라이브에 `HYFLIP_신청시스템_데이터시트_v1.0.xlsx`를 업로드합니다.
2. 파일을 열고 **파일 > Google Sheets로 저장**을 누르면 구글 시트 사본이 생깁니다. 이후 작업은 이 사본에서 합니다.
3. 회색 예시 행(2행)을 지웁니다. 대상 탭은 `신청목록`, `신청상세`, `개설과목`입니다.
   - `신청목록` 2행은 **행 전체를 삭제**하세요. 아래 행의 수식이 한 칸씩 올라와 그대로 이어집니다.
4. 탭 이름과 1행의 열 이름은 **절대 바꾸지 마세요.** 스크립트가 이름으로 찾아갑니다.
   - 예외: `신청목록`의 `대리신청자이메일` 열은 더 이상 쓰지 않습니다. 남겨 두면 빈칸으로 유지되고, 지워도 동작합니다. `현황` 탭 수식이 이 열을 쓰고 있을 수 있으니 **남겨 두는 것을 권장**합니다.

## 2. 설정 탭 입력

| 항목 | 입력 방법 |
|---|---|
| 학기종료일 | 2027-1학기 종료일(학사일정). 보관기간 계산의 기준입니다 |
| 발신계정 | 부서 공동계정 메일 주소. 교수님이 메일에 답장하면 이 주소로 갑니다 |
| PDF폴더ID | 드라이브에 `HYFLIP_신청서PDF` 폴더를 만들고 연 뒤, 주소창 `folders/` 뒤의 문자열을 복사해 붙여넣습니다 |
| 담당자연락처 | 메일 본문에 들어갑니다. 그대로 써도 되는지 확인하세요 |
| 신청페이지URL | 4단계 배포 후 입력합니다 |

## 3. 개설과목 입력

학사시스템에서 2027-1학기 개설과목을 내려받습니다. `개설과목` 탭의 열 순서(학기, 학수번호, 분반, 과목명(한), 과목명(영), 개설학과, 학점, 권장학년, 담당교수)에 맞춰 붙여넣으세요.

- **학기 칸은 `2027-1`로 맞춰야 검색됩니다.**
- 구글 시트는 `2027-1`을 날짜(2027-01-01)로 바꿔버릴 수 있습니다. 붙여넣기 전에 `개설과목`의 학기 열과 `설정`의 모집학기 칸을 **서식 > 숫자 > 일반 텍스트**로 바꿔 두세요. (날짜로 바뀌어도 스크립트가 `2027-1`로 읽도록 보완했지만, 시트에서 보기에도 텍스트가 맞습니다.)

## 4. 스크립트 넣기와 배포

1. 구글 시트에서 **확장 프로그램 > Apps Script**를 엽니다.
2. 기본 파일 `Code.gs`의 내용을 모두 지우고, 받은 `Code.gs` 내용을 붙여넣습니다.
3. 왼쪽 **파일 옆 + > HTML**을 눌러 파일을 두 개 만들고, 각각 받은 파일 내용을 붙여넣습니다.
   - 이름은 `Index`와 `Pdf`로 정확히 입력합니다(확장자 `.html`은 자동으로 붙습니다).
4. 왼쪽 **⚙ 프로젝트 설정 > 시간대**를 `(GMT+09:00) 서울`로 바꿉니다.
5. 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다.
   - 권한 승인 창에서 시트, 드라이브, 메일 발송 권한을 허용하세요.
   - 실행 기록에 "설치 완료: 트리거 2개"가 나오면 성공입니다.
   - 오류가 나면 메시지에 나온 열이나 설정값을 먼저 고치세요.
6. **배포 > 새 배포 > 유형: 웹 앱**을 고르고 다음과 같이 설정한 뒤 배포합니다.
   - 실행 사용자: **나** (부서 공동계정)
   - 액세스 권한: **한양대학교 내 모든 사용자**
7. 나온 웹 앱 URL을 설정 탭의 `신청페이지URL`에 붙여넣습니다.

> 코드를 고친 뒤에는 **배포 > 배포 관리 > 편집(연필) > 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 바뀌지 않습니다.

## 5. 내부 테스트 체크리스트 (12/4 예정)

- [ ] 개인 Gmail 계정으로 URL을 열면 "접근 권한이 없습니다"가 나온다
- [ ] 새 신청서 → 동의 → 기본정보에서 과목 검색 → 선택하면 자동으로 채워진다
- [ ] 임시저장 → 목록으로 → 다시 열기 → 작성하던 단계와 내용이 그대로다
- [ ] 평가 비율 합계가 100%가 아니면 다음으로 넘어가지 않는다
- [ ] 영상 주차가 Smart-F 8주, Smart-B 4주 미만이면 넘어가지 않는다
- [ ] 제출하면 접수번호(FL-2027-1-001)가 생기고, PDF가 폴더에 저장되고, 접수 안내 메일이 온다
- [ ] **PDF를 열어 한글이 깨지지 않는지, 표가 잘리지 않는지 확인한다**
- [ ] 마감 전 수정 후 다시 제출하면 PDF가 새로 바뀌고 이전 PDF는 휴지통으로 간다
- [ ] 첫 화면(안내·동의)에 대리신청 체크박스가 없고, "신청 계정"에 로그인한 본인 메일이 보인다
- [ ] 교수 A 계정으로 만든 신청서는 다른 학교 계정(행정팀 등)의 목록에 보이지 않고, 열 수도 없다
- [ ] 제출하면 접수 안내 메일이 교수 본인에게만 간다(참조 없음). PDF 상단에 "대리신청" 표시가 없다
- [ ] 첫 단계에서 "다음"을 누르자마자 "임시저장"을 눌러도 목록에 (미제출)이 하나만 생긴다
- [ ] 선정상태를 바꿨을 때 다음과 같이 동작한다
  - [ ] **심의중:** 메일이 가지 않는다
  - [ ] **미선정(사유 없음):** 셀에 "메일 미발송" 메모가 붙는다 → 사유를 넣고 다시 고르면 메일이 간다
  - [ ] **보완요청:** 보완내용과 보완기한을 넣은 뒤 고르면 메일이 간다 → 교수가 수정해 제출하면 상태가 '접수'로 돌아간다
  - [ ] **선정:** 선정 메일이 간다
- [ ] `현황` 탭 건수가 맞다

## 6. 운영 시 유의사항

- **처리 한도:** 신청목록의 수식과 드롭다운은 1,000행까지 깔려 있습니다. 한 학기 신청 규모로는 충분합니다.
- **보관기간 자동 처리:** `monthlyCleanup`이 매월 1일 03시에 자동 실행됩니다.
  - 2년이 지나면 이메일·휴대폰·PDF를 지웁니다. (`대리신청자이메일` 열이 남아 있으면 함께 비웁니다.)
  - 10년이 지나면 행 전체를 지우고 `삭제대장`에 기록합니다.
  - 제출하지 않은 임시저장(`신청상세`의 `TMP-` 행)은 마지막 저장일로부터 2년이 지나면 지우고 `삭제대장`에 기록합니다.
- **PDF 공유:** PDF는 신청 교수 본인에게만 보기 권한으로 공유됩니다. 이때 구글이 공유 알림 메일을 보낼 수 있습니다.
- **메일 문구:** `메일문구` 탭의 제목·본문을 고치면 다음 발송부터 바로 반영됩니다. `{중괄호}` 키 이름은 바꾸지 마세요.
- **대리신청 불가:** 행정팀이 교수님 대신 작성할 수 없습니다. 교수님이 직접 로그인해 신청하도록 안내해 주세요. v1.0에서 대리신청으로 만든 신청서가 있으면 책임교수로 지정된 교수님만 열 수 있고, 교수님이 다시 제출하면 본인 신청서로 바뀝니다.
- **수정 가능 기간:**
  - 마감 시각이 지나면 새 신청과 수정이 막힙니다.
  - 단, **보완요청** 상태인 신청서는 보완기한 날까지 수정할 수 있습니다.

## 7. 알려진 제약

- **PDF 글꼴:** PDF는 구글 드라이브의 HTML→PDF 변환으로 만듭니다. 테스트에서 글꼴이나 줄바꿈이 어색하면 알려주세요. 문서 템플릿 방식으로 바꿀 수 있습니다.
- **2단계 예정:** 셀프스튜디오 예약 모듈은 같은 시트의 `스튜디오` 탭을 써서 이어서 개발합니다.
